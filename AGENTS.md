# Agent Guidelines

## Package Manager
- **Always use `pnpm` instead of `npm`** for installing dependencies, running scripts, and managing packages across this repository (e.g., `pnpm install`, `pnpm run build`, `pnpm run dev`, `pnpm add <pkg>`). Do not use `npm` or `yarn`.

## Git Workflow
- **Always commit and push** your changes to the remote repository when completing tasks, creating posts, or making updates.
- Keep commits clear and descriptive.
